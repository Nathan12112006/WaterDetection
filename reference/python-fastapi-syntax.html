Quick reference

Python syntax used by this service

from package import NameLoad one named object from a module.
@decoratorPass the function below through another function that adds behavior.
async def name(...):Define a function that can cooperate with asynchronous work.
parameter: TypeAnnotate the expected parameter type.
-> ReturnTypeAnnotate the expected return type.
Literal["a", "b"]Describe a value restricted to listed choices for type-aware tools.
Annotated[Type, metadata]Keep the Python type while attaching metadata FastAPI can inspect.
try: ... finally: ...Always run the cleanup block, even when an error occurs.
yieldPause a generator; in a lifespan context manager it separates startup from shutdown.
name=valuePass a keyword argument, making the argument's purpose explicit.
