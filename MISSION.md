# Mission: Read the YOLO service line by line

## Why
Learn enough Python and FastAPI syntax to read this project without treating any line as magic, and to explain what each statement contributes when the service runs.

## Success looks like
- Explain each line of the project in plain language.
- Trace when a line runs: import time, startup, request handling, or shutdown.
- Make small changes while predicting their effect before running the code.

## Constraints
- Use short lessons focused on one small code section.
- Prefer simple explanations before framework terminology.
- Build retention with quick prediction and recall exercises.

## Out of scope
- Advanced performance tuning and distributed deployment until the syntax is comfortable.
